Ulanish usuli

Tavsiya etiladi. Ilova ommaviy bepul proksilarni o‘zi topadi va tekshiradi, ishlamay qolsa boshqasiga o‘zi o‘tadi — Telegram’dagi kabi.

Server kerak emas — ilova ichidagi Tor ko‘priklar orqali ulanadi. Ko‘prik osilib qolsa, ilova o‘zi keyingisiga o‘tadi. Birinchi ulanish 30–120 soniya, keyingilari tezroq.

O‘z ko‘priklaringiz (ixtiyoriy, eng ishonchli yo‘l)

Telegram’da @GetBridgesBot ga yozing → webtunnel yoki obfs4 ko‘prik oling → shu yerga to‘liq qo‘ying. Bir nechta qator bo‘lsa ham bo‘ladi.

Proksisiz, to‘g‘ridan-to‘g‘ri. Faqat Instagram bloklanmagan joyda ishlaydi.

Server manzili
Proksi qayerdan olinadi?
  1. Instagram ochiq bo‘lgan davlatda arzon server (VPS) oling.
  2. Unda HTTPS proksi ishga tushiring — bloklovchi tizim uni ko‘ra olmaydi. HTTP va SOCKS5 ham ishlaydi, lekin ular osonroq aniqlanadi.
  3. Manzilni shu yerga yozing: https://domen:443, http://1.2.3.4:8080 yoki socks5://1.2.3.4:1080.
  4. Login/parol faqat HTTP va HTTPS proksilarda ishlaydi.
