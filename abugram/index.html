Частые вопросы

Xabarlarim xavfsizmi?Мои сообщения в безопасности?

Ha. Xabarchi Telegram'ning ochiq kodidan qurilgan va xuddi shu shifrlashdan foydalanadi. Proxy egasi xabarlarni o'qiy olmaydi — u faqat IP manzilni ko'radi.

Да. Xabarchi собран из открытого кода Telegram и использует то же шифрование. Владелец прокси не может читать сообщения — он видит только IP-адрес.

Bu rasmiy Telegram'mi?Это официальный Telegram?

Yo'q, bu norasmiy mijoz. Telegram bunday ilovalarga ruxsat beradi. Ko'rinmas rejim kabi Telegram qoidalariga zid bo'lishi mumkin funksiyalar hammaga berilmaydi: ular faqat admin ruxsat bergan hisoblarda ochiladi.

Нет, это неофициальный клиент. Telegram разрешает такие приложения. Функции вроде невидимки, которые могут нарушать правила Telegram, доступны не всем: только аккаунтам, которым разрешил администратор.

Rasmiy Telegram'ni o'chirishim kerakmi?Нужно ли удалять официальный Telegram?

Yo'q. Xabarchi alohida ilova — ikkalasi ham turadi va bir hisob bilan ishlaydi.

Нет. Xabarchi — отдельное приложение, оба работают с одним аккаунтом.

VPN'siz ulanmasa nima qilay?Что делать, если не подключается без VPN?

Sozlamalar → Xabarchi → Proxy ro'yxati bo'limida ishlayotgan (yashil) proxy'ni tanlang. Ro'yxat har soatda yangilanadi.

Откройте Настройки → Xabarchi → Список прокси и выберите рабочий (зелёный). Список обновляется каждый час.
